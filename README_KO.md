# BLACKOUT PWA

무료로 배포해 안드로이드 홈 화면에 설치할 수 있는 웹앱 프로젝트입니다.

## 현재 기능
- 안 좋은 일/과거 기록 작성
- 원문을 텍스트로 작성
- 원문 영역을 검은 직사각형으로 덮기
- 검은 영역 위에 흰색 텍스트로 새로운 관점/위로의 문장 작성
- 선택적으로 손가락으로 검은 잉크를 추가 칠하기
- 실행 취소 및 덮개 초기화
- 설정에서 과거 원문 다시 보기 허용/차단
- 브라우저 로컬 저장
- JSON 백업 내보내기/가져오기
- PWA 오프라인 캐시

## 안드로이드에서 설치하는 무료 방법 (GitHub Pages)
PWA를 홈 화면 앱으로 설치하려면 HTTPS 주소가 필요합니다. GitHub Pages는 공개 저장소 기준 무료입니다.

1. GitHub 계정에 로그인하고 새 **Public repository**를 만듭니다. 예: `blackout-journal`
2. 이 폴더 안의 `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg` 파일을 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 및 `/ (root)`를 지정한 뒤 Save를 누릅니다.
5. 몇 분 후 표시되는 `https://계정이름.github.io/blackout-journal/` 주소를 안드로이드 Chrome에서 엽니다.
6. Chrome 메뉴(⋮)에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.

## 주의
- 이 프로젝트를 바로 열어 실행할 수는 있지만, 홈 화면 설치 및 오프라인 PWA 기능은 HTTPS로 배포한 뒤 사용할 수 있습니다.
- 기록은 해당 브라우저의 localStorage에 저장됩니다. 브라우저 데이터 삭제, 앱 제거, 기기 변경 시 기록이 사라질 수 있으므로 설정에서 JSON 백업을 주기적으로 내보내세요.
- 원문 보기 설정은 화면 표시를 제어할 뿐, 원문을 암호화하거나 완전히 삭제하지 않습니다.
- 저장된 기록은 클라우드에 동기화되지 않습니다.
